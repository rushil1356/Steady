# Steady frontend

React 19 + TypeScript + Vite + Tailwind. One codebase, two phone-first apps: `/patient` and `/caregiver`.
See the root `README.md` for how to run everything. Vite proxies `/api` and `/static` to the backend on port 8000.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-checks, then builds
```
